# The Spelling Code

A children's phonics and spelling web app (Vite + React). Live at https://the-spelling-code.netlify.app

**Everything is documented in one place:** [docs/THE-SPELLING-CODE.md](docs/THE-SPELLING-CODE.md) — project notes, the full curriculum (every lesson and question), the content library, and a map of the code. That file is generated: edit [docs/project-notes.md](docs/project-notes.md) and the JSON in `content/`, then run `npm run docs`.

```bash
npm install
npm run dev      # http://localhost:5173
npm test         # includes a check that the master document is up to date
npm run docs     # regenerate the master document
npm run build    # production build
```
